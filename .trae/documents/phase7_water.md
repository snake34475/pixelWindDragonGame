# Phase 7：水域表现实施复盘

> 日期：2026-09-27
> 基线：`02b87de`（`feat: add NPC dialog interaction`）
> 引擎：Godot 4.7.2

## 目标

玩家进入池塘后产生可见的入水表现，离开后恢复；水域保持非实体障碍，
反复进出不能留下状态或颜色残留。

## 交付物

| 文件 | 作用 |
| --- | --- |
| `scripts/world/water_zone.gd` | 检测玩家进入和离开 |
| `scripts/player/player.gd` | 记录重叠水域数量并应用入水颜色 |
| `scenes/levels/town_map.tscn` | 池塘接入 `WaterZone` 和玩家检测掩码 |
| `tests/test_water.gd` | 水域表现无头测试（11 项） |

## 关键决策

1. Unity 的 `Swimming.cs` 只有离开恢复代码，进入设置被注释；Godot 按既有设计目标实现完整进出。
2. 池塘使用 Godot 第 7 层位掩码 `64`，并检测玩家层 `2`，不参与实体阻挡。
3. 玩家用水域重叠计数而不是布尔值切换，支持多个水域重叠。
4. 当前表现采用蓝色半透明 `modulate`，不引入自定义 Shader。

## 已知限制

- 当前只用颜色与透明度表达入水，没有还原 Unity 的 Sprite Mask 下半身遮罩。
- 后续若要提升表现，可增加水面覆盖层，不影响现有进出状态逻辑。
